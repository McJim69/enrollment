## ✨ Overview
The **Student Enrollment System** is a PHP/MySQL web application designed to automate and simplify the enrollment process.  
It reduces manpower requirements, eliminates duplicate entries, and ensures a smooth experience for both students and administrators.

---

## ⚙️ How It Works
Students can enroll in their subjects online before the semester begins.  
The system provides two main modules: **Public/User Facing** and **Admin Facing**, covering the entire enrollment workflow.

---

## 🚀 Key Features
- **[Student Accounts](ca://s?q=Explain_Student_Accounts_in_Enrollment_System)** – create accounts and complete enrollment forms.  
- **[Academic Entries](ca://s?q=Explain_Academic_Entries_in_Enrollment_System)** – manage Students, Courses, Subjects, Departments, and Faculty.  
- **[Advising](ca://s?q=Explain_Academic_Advising_in_Enrollment_System)** – Deans can advise students on subject selection.  
- **Class Listing & Scheduling** – organize classes and timetables.  
- **Faculty Subject Loading** – assign subjects to faculty members.  
- **Query Filters** – advanced search for different entries.  
- **Unit Assessment** – assign and evaluate the number of units per student.  
- **Database Tools** – backup, restore, and empty database options for administrators.

## 👩‍💼 Management Features

### General
- Login required for administrators.  

### Public/User Facing
- Students can create accounts and fill out enrollment forms.  

### Admin Facing
- Manage entries for Students, Courses, Subjects, Departments, and Faculty.  
- Class listing and scheduling.  
- Faculty subject loading.  
- Query filters for data management.  
- Assign and assess units.  
- Backup, restore, and empty database.
